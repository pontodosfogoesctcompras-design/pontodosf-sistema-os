# 🌐 Como Hospedar no GitHub Pages

## Passo 1 — Upload dos arquivos

1. Acesse: https://github.com/pontodosfogoesctcompras-design/pontodosf-sistema-os
2. Clique em **"Add file"** → **"Upload files"**
3. Arraste os arquivos:
   - `index.html` (pasta sistema/)
   - `AppsScript_FINAL.gs` (pasta scripts/)
   - `README.md`
4. No campo "Commit changes" escreva: `Sistema OS v3.0`
5. Clique **"Commit changes"**

## Passo 2 — Ativar GitHub Pages

1. No repositório clique em **Settings** (aba superior)
2. Menu lateral esquerdo → **Pages**
3. Em "Source" selecione: **Deploy from a branch**
4. Branch: **main**
5. Folder: **/ (root)**
6. Clique **Save**
7. Aguarde 2-3 minutos

## Passo 3 — Acessar o sistema

A URL ficará disponível em:
https://pontodosfogoesctcompras-design.github.io/pontodosf-sistema-os/sistema/

1. Abrir o link no **Chrome**
2. Menu (três pontos) → "Adicionar à tela inicial"
